# 日常开发模板包

这组模板用于把 Trellis 任务、PRD 和验证清单压成团队可直接复制的标准格式。

## 文件说明

- `task.md` - Trellis 任务模板
- `prd.md` - 需求说明模板
- `verification.md` - 验证清单模板

## 使用建议

1. 新任务先复制 `task.md`
2. 中等及以上任务补一份 `prd.md`
3. 开发完成前后都跑一遍 `verification.md`
4. 需要会话延续时，把本次关键结论同步到 `.trellis/workspace/`

## 约定

- 这些模板只负责格式，不替代 `AGENTS.md`
- 这些模板也不替代 `.quality-rhythm` 和 `.ccg`
- 任何真实改动仍然要遵守仓库原有质量门禁
