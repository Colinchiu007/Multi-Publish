# 启动应用

用当前项目最新代码 + 已登录 profile 启动 Multi-Publish 桌面应用。

详细定义见 `.codex/skills/start-app/SKILL.md`。

## 执行要点

1. **同步最新**：`git fetch origin` + 核对 `HEAD...origin/main` 落后数，落后则 `git merge --ff-only origin/main`（冲突即停，不丢改动）。
2. **环境齐备**：`node scripts/ensure-desktop-deps.js --check`（缺失自愈）、确认 electron 二进制存在。
3. **带登录态启动**（推荐）：
   ```powershell
   pwsh -File scripts/start-desktop.ps1 -Worktree <工作区> -Profile 'D:\tmp\Multi-Publish-debug-profile' -CheckIdentity -Json
   ```
4. **验证**：`START_CONTRACT_OK` + 窗口 handle + identity 登录态。
