# 模型密钥「设为默认」需求（规格真相源：openspec change ops-center-provider-default-mark）

## 需求
运营后台「模型密钥」列表，为已保存的 provider 密钥增加「设为默认」操作；**同类（用途分组）只能有一个默认**（用户已确认：按 LLM/视觉/生图用途分组唯一）。

## 用途分组（唯一性作用域）
- LLM：`minimax-llm`
- 视觉：`minimax-vision`, `opencode-go-vision`
- 生图：`minimax-image`, `flux`, `hunyuan`

## 行为契约
1. 列表展示每个密钥的 `is_default` 标记（前端「默认」徽标）。
2. 设为默认：目标密钥 `is_default=1`，同分组其他密钥清 0（事务内）。
3. 只允许启用中的密钥设为默认；禁用密钥请求设为默认 → 400 明确提示。
4. 新保存的密钥：若其分组尚无默认 → 自动成为默认；已有默认则保持不变。
5. 编辑密钥时若把当前默认键禁用 → 默认标记清空（不自动转移）；删除默认键后默认标记随之消失。
6. 选择链路生效：LLM（中英对照）与视觉评估取默认键优先，无默认时保持现有「最新启用」回退。

## 验收标准
- 后端：PUT /api/v1/prompt-eval/providers/{key_id}/default（admin）分组唯一、404/400/403 齐全；列表含 is_default。
- 前端：默认徽标 + 设为默认按钮（互斥提示/置灰）。
- 测试：分组唯一、跨分组互不影响、禁用拒绝、404、非 admin 403、选择链路优先默认、迁移幂等补列。
