# 视频创作历史记录卡片与详情编辑增强

## 基线差异审计

### 已交付基线能力

- CreateViewHistory.vue 已有六个状态标签、确定性时间排序、暂停/失败专项信息和项目卡片合并展示。
- Story2VideoProjectService 的大多数项目写路径已经在保存时刷新 updatedAt。
- ResultView.vue 已能在存在 projectId + segments 且没有成片时渲染分段编辑区，场景素材槽已有空槽“未生成”文案。
- CreateView.openHistoryResult 已允许有项目 ID 的运行中、暂停、失败和完成任务进入视频任务编辑页，但明确排除了已取消任务；CreateViewHistory 的编辑按钮只对已完成项目显示。

### 待实现/待确认

- 所有状态卡片统一展示标题、文案预览、缩略图、视频时长，且标题空时从任务文案回退。
- “提示词预览”字段改为“文案预览”，预览内容使用任务文案而不是图片提示词；空白/缺失字段安全回退并按固定长度截断。
- 首个场景片段的缩略图选择：同一场景有图片时取第一张图片；没有图片时取第一个视频首帧。首帧生成必须由主进程使用受控路径、execFile 和临时文件原子写入，失败时回退空占位，不阻塞历史列表。
- 视频时长采用成片时长，缺少成片时回退首个可用片段视频/项目时长；数值非法时显示本地化未生成/不可用状态，不显示 undefined。
- 文案内容变更、保存素材、暂停、从断点继续、取消、失败/完成状态写回时刷新同一项目的 updatedAt，历史合并不能用较旧 run 字段覆盖较新的项目时间。
- 已启动且非 running 的项目，包括 cancelled，可以进入视频任务编辑页，详情中的图片、视频、提示词、翻译、字幕、语音等缺失或生成失败字段保留稳定布局并显示“未生成”占位。

## 数据校验和兼容性

- project/run ID 仅使用非空安全标识；缩略图输入路径不从 renderer 接受，来自项目服务已校验的项目素材路径。
- 缩略图持久化 canonical 文件路径，不持久化短生命媒体 URL；renderer 读取历史时通过现有媒体 URL IPC 重新解析。
- 图片按项目允许的图片根目录和扩展名校验；视频首帧输入按视频根目录、普通文件、大小限制和符号链接防护校验。
- 失败或不存在的素材不抛出导致历史列表失败，使用 thumbnailStatus=missing|failed 和详情占位；技术错误仅写受控日志/结构化字段，不直接显示堆栈。
- zh/en 用户可见文案必须成对维护，新增术语先遵守 01-docs/i18n-glossary.md。

## 验收标准

1. 六个状态标签中的每一张卡片都有标题；标题为空时显示任务文案截断值，再无文案才显示流水线名/未命名。
2. 卡片字段显示“文案预览”和文案内容，超出产品固定上限时只保留上限前字符并追加 …。
3. 图片优先、视频首帧回退的缩略图策略在有图、仅视频、全部缺失、视频首帧生成失败四种路径可验证。
4. 每张卡片显示视频时长或稳定的未生成/不可用占位。
5. 内容编辑、暂停、继续、取消后的历史有效更新时间均比操作前新；旧数据仍按既有候选字段安全回退。
6. running/paused/failed/completed/cancelled 五种已启动状态均可从卡片主体或编辑动作进入 /create/result?project=...；取消任务不触发恢复。
7. 详情页中缺失/失败的图片、视频、提示词、翻译、字幕、语音不塌陷、不显示原始异常对象，显示“未生成”并保留可用编辑/重试入口。
8. 受影响单元测试、locale 检查、git diff --check、renderer 构建通过；修改 Electron 主进程后执行 QM-1 打包和 packaged smoke。
