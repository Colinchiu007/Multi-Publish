# 调查范围

## 目标

确定故事讲述（`story2video-compose`）实际生成字幕时，是否使用了
`smart-sentence-splitter` 的最新算法与输出；对用户提供的五段中文文本
复现在线与本地路径的字幕分块，解释截图中的不合理断点。

## 验收标准

- 明确运行时 `SplitterBridge` 启动的实际工作目录、代码版本/提交与 API 响应。
- 明确字幕最终使用的来源：引擎 `scenes[].subtitles`、本地镜像，或旧路径。
- 给出五段样本文本的可复现分块输出及所用配置。
- 用源码、运行日志或 HTTP 结果解释每个截图问题的直接原因。
- 若发现缺陷，给出最小修复范围、回归测试位置和防回归建议；本调查不修改产品运行时代码。
