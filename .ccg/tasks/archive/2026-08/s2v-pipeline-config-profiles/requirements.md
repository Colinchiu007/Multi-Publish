# 需求增强：视频创作流水线保存配置

## 用户目标

用户可以在视频创作页把当前流水线的可配置选项保存为一个有名字的组合配置；下次打开配置管理后，点击应用即可把这组选择回填到当前表单。配置必须可重命名、删除，并且不能把素材、凭证或运行状态带入持久化数据。

## 功能边界

### P0

- 所有可进入通用 CreateView 配置表单的流水线都显示“保存配置”和“我的配置”。
- 编排流水线保存 `s2vConfig` 与 `s2vOutputConfig` 的显式白名单字段；普通流水线保存 `inputMode`、样式、LLM、预算、检查点、分镜和输出配置。
- 设备级 CRUD：列表、创建、同名覆盖、重命名、删除。
- 同流水线匹配才能应用；跨流水线按钮禁用，方法入口仍二次校验。
- 应用已修改表单时展示确认；取消不改字段，确认按当前打开时的目标配置执行。
- 应用完成后运行枚举、数值、分辨率和 provider 可用性归一化；无效 provider/model/voice 清理或回退。
- 保存/应用/重命名/删除失败展示用户可读原因，不泄漏路径、堆栈、凭证或内部对象。

### P1

- 保存 UI 展示名称、流水线名、更新时间及操作按钮；名称输入 `maxlength=60`。
- 配置管理弹窗加载中可关闭，关闭后异步结果不得重新打开或覆盖当前状态。
- `story2video.lastOptions.v1` 与具名配置互相独立：应用具名配置不触发或覆盖上次选项持久化。
- 音色目录异步刷新不得清空刚应用且仍在当前目录中的 voiceId。

## 数据校验

- `pipelineId` 仅允许 `[A-Za-z0-9][A-Za-z0-9._-]*`，长度 1–64。
- 名称 trim 后按 Unicode code point 计数，长度 1–60。
- profile id 仅接受 `[A-Za-z0-9-]{8,64}`；新 ID 使用 `randomUUID`。
- snapshot 必须是 plain object，JSON UTF-8 序列化不超过 64 KiB。
- 单流水线最多 50 条；写入使用临时文件加原子 rename，并对 Windows 占用错误有限重试。
- 缺失/损坏 JSON 读路径安全降级为空库；可解析但含非法条目的索引只允许读取合法项，写操作必须 fail closed 且不覆盖原文件。

## 测试与证据

- 服务单测覆盖校验、CRUD、原子写、损坏/部分损坏索引和大小/容量边界。
- IPC 单测覆盖四通道 sender、参数校验和错误码。
- CreateView 单测覆盖快照白名单、所有流水线类型、应用归一化、provider/voice、确认期间切换、加载关闭竞态和 lastOptions 抑制。
- 完成后分别记录 focused/full Vitest、locale/lint/type/build/package、ASAR/require、可见窗口和远程 CI/merge 证据。
