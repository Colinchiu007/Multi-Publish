# Story2Video UE 与空白页修复需求

## 目标

在不改变通用流水线人工 checkpoint 合同的前提下，将 `story2video-compose` 的创作表单改成确认后的“快速模式 + 五个折叠区”，并修复点击“视频创作”时动态路由失败只呈现空白的问题。

## 产品合同

- 稳定机器 ID 继续使用 `story2video-compose`，中文外显为“图片轮播”，英文外显为“Image Carousel”。
- 图片轮播启动按钮显示“启动流水线”，提交后固定使用 `autoAdvance=true`、`checkpointPolicy='none'`，不要求人工继续或确认。
- 运行态使用六项阶段清单：文案拆分、内容增强、画面提示词优化、生成图片与旁白、合成轮播视频、发布（可选）；不显示 Story2Video 百分比进度。
- 表单采用“基础 / 外观 / 声音 / 高级 / 发布”五个可折叠区，仅基础默认展开；保留既有字段和数据能力。
- 分句语言默认“自动识别”；音调、并发数、创意强度不作为用户输入显示，仍通过受控默认值发送。
- 图片风格与提示词风格继续保留为两个独立选择，并在界面解释前者控制最终视觉、后者控制提示词组织。
- 用户音色克隆文件管理归属于前端用户；运营后台 `D:\Data\projects\ops-center` 只作为未来受控默认配置来源，本任务不接入其运行时分发。
- TTS 真实供应商目录、个人槽位、克隆上传和图片敏感词降级的真实账号验收仍属于外部验证边界，不能由本地测试宣称完成。

## 空白页合同

- `/create` 动态 import 失败时必须呈现用户可见错误占位，而不是裸 `router-view` 白屏。
- 占位至少提供重试和刷新入口，并保留错误摘要；路由错误不得吞掉 renderer console 证据。
- 正常加载路径不能改变已有 `CreateView` 组件行为。

## 验收范围

- Vue 构建成功，路由错误边界测试覆盖动态 import 失败、重试和刷新。
- Story2Video 表单折叠区、隐藏字段、默认语言、按钮文案和六阶段清单有稳定 `data-testid`/功能测试。
- 通用流水线的 guided/manual checkpoint 测试继续通过。
- 真实 Electron 窗口点击“视频创作”不出现空白；renderer console 无动态 chunk/import 错误。
- 真实 provider 验收单独标记为 `PENDING_EXTERNAL`。
