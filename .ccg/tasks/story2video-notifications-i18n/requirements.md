# Story2Video 通知与文本输入契约

## 用户问题

1. Story2Video 运行错误目前同时出现应用内弹窗和页面内红色错误条，造成重复提示。
2. `Story2Video optimize scene count exceeds the allowed limit: 60` 是不符合产品需求的场景数量限制；Story2Video 不以场景数拒绝用户输入，只限制文案文本输入框。
3. 提示/错误文案散落在前后端，英文原始错误直接暴露给默认中文用户，无法集中维护或切换语言。

## 验收标准

1. Story2Video 的用户可见错误/提示仅显示一次：通过应用内弹窗展示；错误状态与历史记录继续保留，但页面不再显示重复红色提示条。
2. 文案输入按 Unicode 字符计数，允许 `1..6000` 个中文或英文字符；超过 6000 时阻止启动并显示友好提示。不得因分句后的场景数拒绝 Story2Video 运行。
3. 创建独立、可维护的通知消息模型/目录，至少支持 `zh-CN` 和 `en-US`；默认中文；前端与 Story2Video 后端对已知用户可见提示使用稳定消息键，而非散落的英文字符串。
4. 所有本次覆盖的 Story2Video 提示与错误均提供中英文版本；中文默认文案面向普通用户，避免暴露“scene count”“API Key”等技术细节。
5. 通过 TDD 覆盖：重复展示、6000 字符边界、无场景数量拒绝、中英翻译回退、后端消息键/响应契约；并更新复盘与质量门禁学习记录。
6. 用打包 Electron 窗口验证：中文默认弹窗只出现一次；英文切换能显示英语；超 6000 字符提示友好；正常短文案可启动 Story2Video。
