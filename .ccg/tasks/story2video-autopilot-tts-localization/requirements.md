# 图片轮播自动流水线、TTS 音色与多语言体验需求基线

## 本轮范围

- 收敛并交付当前仓库与所有已登记工作树中可安全合并的有效改动。
- 将原 Story2Video 流水线更名为“图片轮播”，并以 i18n 资源驱动中英文显示。
- 将原引导式流程改为在用户提交参数后自动连续执行的流水线；提交按钮显示“启动流水线”，执行进度改为阶段清单。
- 隐藏音调、并发数、创意强度，使用默认或运营后台配置；分句语言默认“自动识别”。
- 明确图片风格与提示词风格的语义关系，并据此去重或保留。
- 设计并实施按 TTS 模型绑定的内置音色、个人音色槽位和音色复制能力；模型能力和约束持久化。
- 为图片生成拒绝类失败提供受控的提示词风险分析、重写重试和第五次失败后的可操作提示。
- 补充 PRD、相关项目文档与最近会话中应落地的需求；给出独立的 Story2Video UE 优化建议，待用户确认后才实施建议中的额外信息架构调整。

## 音色偏好与失效合同

- 音色目录按 `providerId + modelId` 作用域缓存；用户偏好也必须绑定该模型，切换模型不得复用不匹配的 `voiceId`。
- 清除用户偏好时恢复该 provider/model 的安全默认音色（或 provider 默认），不得写入伪造的空音色；删除个人/克隆音色时必须先使偏好失效，再清理本地样本与 registry，后续读取不得返回已删除项。

## Doubao 边界

桌面端不得持有高权限 Doubao secret；在后端 connector、官方个人槽位 API 和安全授权链交付前，不显示或生成“个人音色列表”，仅提供官方控制台说明与 `unsupported`/`unavailable` 状态。

- 音色样本管理归属桌面端：用户上传、保存、删除、设默认及 owner-scoped userData/SQLite 元数据均是前台用户功能；OpsCenter 不保存或管理用户音频样本，仅服务运营受控默认值和未来后台高权限凭据/目录同步。
