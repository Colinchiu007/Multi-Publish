# Story2Video 参数边界与真实运行验证

## 用户目标

- 确认视频创作中 Story2Video 界面的参数和选项是否混入了 OpenMontage 多条流水线的通用配置。
- 仅保留 Story2Video 自身的必要参数和选项；移除无关配置，不影响其他流水线。
- 对照 `D:\Data\projects\Story2Video` 的 PRD、架构、功能、流程和代码，确认产品边界。
- 使用当前桌面环境已配置的推理、图片、语音模型 API Key，实际执行一次 Story2Video 视频生成；若失败，定位根因并让界面提供可见错误。

## 验收标准

- 参数归属具备可追溯证据：当前实现、原项目合同、运行时消费点三者一致。
- 移除项不再出现在 Story2Video 配置界面、配置归一化或执行请求中。
- 保留的 Story2Video 参数仍能在配置、项目持久化和六阶段执行链正确传递。
- 真实桌面/服务编排入口完成一次最小可控视频生成；若外部服务拒绝或配额不足，界面显示可行动错误而非静默失败。
- 聚焦测试、前端构建、真实 ffmpeg/视频输出验证和双模型审查完成。
