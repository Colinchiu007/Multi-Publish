# 字幕语义边界修复需求

## 问题

在 `min=8/max=15` 时，用户文案会输出 `对汉地的管理极其粗放，江南`，而不是让逗号后的 `江南` 归入下一块；同时 `江南士绅摇身一变成了蒙元的包税人` 未在 `摇身一变｜成了` 处分块。

## 验收标准

给定用户原文，TS、Electron JS 与 smart-sentence-splitter Python 三端逐字输出：

```text
那时候蒙古统治者水平有限
对汉地的管理极其粗放
江南士绅摇身一变
成了蒙元的包税人
大汗把权力一下放
收税成本蹭蹭往下降
```

并且：

- `江南`、`蒙古`、`包税人`、`大汗` 不得被切开；
- 逗号切点优先于把后续完整短语吸附到前块；
- 三端共享规则保持同步；
- 既有字幕向量、parity、Electron 定点测试和 sidecar 测试通过。
