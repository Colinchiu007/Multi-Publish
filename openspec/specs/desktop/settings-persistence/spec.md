# desktop/settings-persistence Specification

## Purpose
规定桌面端主进程「应用设置」真源的读写契约：配置一经写入，必须能在应用重启后被语义等价地读回，且这条往返对称性由真实存储的回归锁守住，而不是由 mock 的自我一致守住。它覆盖所有把设置表当唯一真源的恢复路径（运营下发配置、上报水位线等）。
## Requirements
### Requirement: 设置真源读写往返必须类型对称

以「应用设置」真源持久化的任意 JSON 兼容值，SHALL 满足往返对称：写入什么语义值，读回即为该语义值（对象仍为对象、数字仍为数字）。系统 MUST NOT 因读侧与写侧对返回值类型的假设不一致，而使读回结果静默退化为空值或默认值。

归一化判据 SHALL 由存储侧的**唯一实现**持有，消费方直接复用；MUST NOT 新增第二份剥壳/类型分支逻辑（两份必然漂移）。存量已有的重复归一化点若行为正确，可登记为后续收敛，但 MUST NOT 被当作"本契约已由多处实现满足"的依据。

#### Scenario: 对象配置跨重启读回等价

- **WHEN** 某服务把一份含嵌套对象与字符串字段的配置写入设置真源，随后以同一份持久化数据新建该服务实例（模拟应用重启）
- **THEN** 新实例读回的配置与写入时的语义值逐字段等价
- **AND** 不出现「写入返回成功、读回为空对象」

#### Scenario: 存量行无需迁移即可读回

- **GIVEN** 数据库里存在修复前写入的设置行（值为 JSON 文本）
- **WHEN** 修复后的消费方读取该行
- **THEN** 读回等价的语义值
- **AND** 落盘字节格式不变，本次修复 MUST NOT 引入任何数据迁移步骤

#### Scenario: 损坏行不得污染恢复路径

- **GIVEN** 某设置行的值既不是合法 JSON 也不是可解析内容（人为损坏或半写入）
- **WHEN** 消费方读取该行
- **THEN** 得到该消费方声明的安全默认值
- **AND** 不抛出未捕获异常，也不把损坏内容当成有效配置应用

### Requirement: 恢复型状态必须在重启后生效

凡以设置真源持久化的**恢复型状态**——运营中心下发的应用菜单、公告、功能开关、发布管线选项，以及诊断/发布/用量三类上报水位线——SHALL 在应用重启后按上一份持久化值生效。系统 MUST NOT 出现「写路径报成功、恢复路径恒为默认」的组合。

本要求使 `openspec/specs/app-menu/spec.md` 中「应用菜单配置落入本地缓存，重启后仍可恢复」那条既有要求第一次具备可验证性；它不改变该要求的语义。

#### Scenario: 重启后应用菜单恢复

- **GIVEN** 一次成功同步已把运营中心的应用菜单配置（含显隐与分组排序）落入本地缓存
- **WHEN** 应用重启且运营中心不可达
- **THEN** 侧边栏仍按上次持久化的配置渲染，MUST NOT 回落到应用内置默认菜单
- **AND** 该恢复过程不依赖任何一次新的网络同步

#### Scenario: 从未成功同步时 fail-open 到内置默认

- **GIVEN** 本机从未成功同步过运营配置（设置真源无该键）
- **WHEN** 应用重启并渲染侧边栏
- **THEN** 使用应用内置默认菜单（故障缺席不等于错误）

#### Scenario: 上报水位线不得恒为零

- **GIVEN** 某上报服务已成功上报并写入水位线
- **WHEN** 应用重启后该服务再次决定上报范围
- **THEN** 读回的水位线为非零的上一份值
- **AND** 已上报内容不被重复上报

### Requirement: 恢复路径的回归锁必须用真实存储

覆盖「重启后恢复」语义的测试 SHALL 至少有一条使用**真实的应用设置存储**（真库、真文件、进程内独立临时目录），MUST NOT 只由「输入什么类型就返回什么类型」的同构 mock 覆盖。任何为被测代码准备的存储夹具 SHALL 复现真实存储的类型语义。

#### Scenario: 夹具同形使契约误读当场变红

- **GIVEN** 一份与真实存储同形的夹具（写入 JSON 文本 → 读出解析后的对象）
- **WHEN** 被测服务按「读回即字符串」的误判写法实现读取
- **THEN** 该用例变红（而不是带着错误实现全绿）

#### Scenario: 摘掉恢复动作必须变红

- **WHEN** 把某条恢复路径的实现改成 no-op
- **THEN** 至少一条真实存储回归锁变红
- **AND** 若全部用例仍绿，说明该恢复路径没有被任何锁覆盖，MUST NOT 登记为已受保护

#### Scenario: 测试隔离不得写共享真源

- **GIVEN** 回归锁需要一份可写数据库
- **WHEN** 测试运行
- **THEN** 该库位于系统临时目录下带进程/随机标识的独立路径
- **AND** MUST NOT 指向仓库内共享数据文件（并发会话会同时执行）
