### 遗留（不假装已闭合）

- **suite 维度不进键**：台账里写了 `suite` 只作诊断。后果是"某条命令从一个面迁到另一个面"不会被发现。要不要把 suite 并进键，等出现第一个真实误判再说，现在并进去只会让基线凭空大一倍。
- **"陈旧不判红"使基线天然只增不减**：删除一条必须有"全量跑里持续未出现"的依据，而全量跑要 20 分钟，所以实际执行会靠人。缓解是基线文件里那条 `原因 ≥8 字符` 的夹具锁 + issue #2878 这种显式欠账标记；没有自动收口。
- **partial sink 盲视无法证否**：某个 realm 若连 install 都没写出来（例如它的 `fs` 在守卫装载之前就被替换成谎报对象），这次跑仍然会有别的 realm 的记录撑住"装配未经证实"判据 ⇒ 漏记的只是那一个 realm。现有手段只能把"整体没产出"判红，做不到"每个 realm 都自证写成功"。
- **`ops-center` 的 pytest 面不在域内**：这套只覆盖 node 测试面。
