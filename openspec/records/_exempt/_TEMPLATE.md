# 用法：复制本文件为 `openspec/records/_exempt/<分支名>.md`。
# 只有当本 PR 确实不该产出一篇执行记录时才用；文件名用分支名，因为 squash 合并下
# PR 号在判据运行时还不存在，而 commit sha 每轮 re-sync 都会变——分支名是唯一稳定键。
exempt_for: <分支名>
reason: <为什么这次不写记录（必须非空，空原因一律抛错）>
---

## 豁免说明

- 本文件代表"这个 PR 不产执行记录"的一次显式承认，不是静默绕过。
- 该分支合并后分支会被删除；checker 把它计入「待清理豁免」可见计数，
  累计达到阈值时拦截，删除本文件即放行（删的是自己这个文件，零同行竞争）。
- 同一分支若已存在记录文件，本豁免文件即矛盾，必须删除其一。
