## Purpose

全能创作（Story2Video）水印「移动」位置的多镜头渲染契约：移动水印以成片全局时间轴计时，跨镜头连续漂移、不随镜头切换重置起点。

## ADDED Requirements

### Requirement: 移动水印成片级连续漂移
移动（moving）水印 MUST 以成片全局时间轴 t（0 → 成片总时长）计时并按确定性 Lissajous 轨迹漂移；多镜头成片中，水印在任何镜头切换点 MUST 保持位置连续，不得重置回起点或发生跳变。单镜头成片轨迹 MUST 与既有契约一致（t=0 位于画面中心附近）。

#### Scenario: 多镜头成片跨镜头连续
- **WHEN** 用户生成 ≥2 镜头的成片，水印位置为「移动（平滑漂移）」且镜头切换点位于 30s 处
- **THEN** 成片 29.5s 与 30.5s 两帧的水印位置必须与「以整片 t 计算的 sin 轨迹」连续一致，不得在 30s 处跳回 t=0 的起点位置

#### Scenario: 单镜头成片起点居中有回归
- **WHEN** 用户生成单镜头成片，水印位置为「移动」
- **THEN** t=0 帧水印位于画面中心附近（与 2026-08-27 修复后契约一致），轨迹周期/幅度/确定性不变

### Requirement: 非移动位置渲染不受影响
静态位置（top-left / top-right / bottom-left / bottom-right / center）水印 MUST 保持原逐片段渲染语义，不得因移动水印阶段后置而改变坐标、边距或可见性。

#### Scenario: 四角与居中坐标回归
- **WHEN** 用户选择任一静态位置生成多镜头成片
- **THEN** 每帧水印位置与既有坐标契约（水平/底部 40px、顶部 60px、center 居中）一致，且镜头切换不产生位置变化（静态水印本身无时间语义）

### Requirement: 校验与快照兼容
水印数据校验 MUST 保持既有契约：position 枚举白名单、normalizer fail-closed、快照结构不变；本次渲染阶段变更不得引入新字段或破坏旧快照恢复。

#### Scenario: 旧快照直接生效
- **WHEN** 用户从旧版本快照恢复水印配置（position: moving）
- **THEN** 配置直接生效并渲染为成片级连续漂移，无需迁移或吸附
