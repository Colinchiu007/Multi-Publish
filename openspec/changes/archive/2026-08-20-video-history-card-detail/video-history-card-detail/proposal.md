# Proposal: 视频创作历史记录卡片与详情编辑增强

## Why

视频创作历史记录目前只在部分状态展示可识别的标题和编辑入口，卡片缺少能快速判断任务内容的缩略图与视频时长；运行中/终态的项目数据在 run 与 project 合并后也可能继续使用旧更新时间。详情页对图片/视频之外的提示词、翻译、语音等缺失素材没有统一占位，导致失败任务进入后布局不稳定、用户无法区分“尚未生成”和“字段不存在”。

## What changes

- 统一六个历史状态标签的卡片信息合同：标题、文案预览、场景缩略图、视频时长、更新时间、创建时间、耗时、状态和任务标识。
- 建立图片优先、视频首帧回退的历史缩略图派生和安全缓存路径。
- 统一项目/运行操作的更新时间写回。
- 允许所有已启动且非运行中的任务进入视频任务编辑页，取消任务只查看/编辑，不自动恢复；运行中任务继续使用流水线控制入口。
- 为详情页的图片、视频、提示词、翻译、字幕和语音缺失/失败状态提供稳定的“未生成”占位。

## Non-goals

- 不改变运行中流水线的阶段执行、并发和恢复策略。
- 不把失败任务的技术堆栈或 provider 原始响应直接展示给用户。
- 不在 renderer 中执行 FFmpeg 或接受任意文件系统路径生成缩略图。
