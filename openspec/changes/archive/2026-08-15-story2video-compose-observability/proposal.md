# Story2Video 合成链路可观测性

长列表视频合成可能在 UI 87% 处持续数分钟。现有日志只记录分块完成，无法区分 FFmpeg 尚未启动、持续重编码、输出无增长、超时或 renderer 未收到进度。本 change 为合成引擎建立稳定的结构化事件日志，保留现有进度与执行语义。

## 价值

- 通过 composeId 关联一次合成的所有阶段。
- 通过 FFmpeg 生命周期和输出大小判断真实卡点。
- 通过 chunk 生命周期与心跳定位长列表拼接的具体层级和块。
- 通过安全字段约束避免日志泄露完整路径、命令和素材内容。

## 非目标

- 不改变并发、FFmpeg 参数、转场效果或实际合成顺序。
- 不把高频 FFmpeg progress pipe 引入本 change；后续可独立评估。
