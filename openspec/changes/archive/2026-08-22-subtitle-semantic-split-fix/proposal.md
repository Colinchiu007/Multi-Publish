# 修复字幕语义边界切分

## Why

当前短语保护只禁止切入 `江南` 内部，未表达谓语起点和边界归属。无标点硬切在 `了` 后找到短尾候选，尾块平衡又把 `江南` 单独让出，随后 `mergeShort` 将 2 字短块吸回逗号前块，形成语义不合理的字幕。

## What Changes

- 在共享词边界规则中加入常见谓语起点 `成`，并让有足够尾部的语义引导切点优先于短尾收束切点。
- 保留 `no_cut_bigrams` 的“不拆词”职责，不把短语保护误当成前向吸附规则。
- 将用户样例更新为手工真值，锁定 `粗放｜江南` 和 `摇身一变｜成了` 两个语义边界。
- 同步 TypeScript、Electron JS 与 Python 实现及回归测试。

## Non-goals

- 不引入中文分词依赖。
- 不修改场景级分组、在线字幕质量门或时间戳协议。
