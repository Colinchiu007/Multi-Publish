# 设计

## 决策

`word_split.good_lead` 是现有三端共享的“后块引导字”规则。将 `成` 纳入该集合后，`摇身一变｜成了` 可成为语义候选。另增加 `semantic_lead`，标记“提/还/把/绝”等会开启新动作或判断的引导字。后块以这些字开头时，即使短于 `min_chars`，`mergeShort` 也不再把它吸回前块；硬切后的平衡让字同样跳过这种语义边界。`semantic_lead_followers` 用于约束“提”只在“提前”中生效，避免把普通“提”误当分句点。

保护短语判断继续在所有候选和兜底切点执行，确保不产生 `江｜南` 或 `绝｜对`。逗号边界在 `lengthSplit` 中已经先于硬切产生；本次重点是避免后续短块合并和平衡步骤破坏语义停顿。

## 风险

`成` 与语义引导字规则可能改变少量无标点长句的切点，因此以共享向量、TS/JS parity、Python 向量和定向边界回归验证。
