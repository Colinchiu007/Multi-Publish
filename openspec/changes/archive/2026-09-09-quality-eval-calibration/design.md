## Context

见 proposal.md。v1.0 已将评估器接入改写结果和运营中心，但 clone_divergence 在没有原文时固定为 60 分并参与总分，运营中心也把该值计入最近 100 篇均值。当前结构评分还把首先、其次、最后当作真实分点，尽管逻辑评分把同一模式视作模板。离线校准显示高质量书面叙事被过度依赖网络口语的去 AI 味规则低估。

## Goals / Non-Goals

**Goals:**

- 让每个维度能够明确表示本次输入是否适用，并使综合分和统计只使用适用维度。
- 修复同一模板信号的跨维度矛盾，增加有限且可解释的书面人类表达证据。
- 保持 15 个维度的响应外形，兼容已有记录和调用方。
- 用离线人工参考/模板对抗集锁定可复现的校准底线。

**Non-Goals:**

- 不把词汇启发式升级为事实核验、深层语义理解或外部 LLM 裁判。
- 不因模板文本可读或关键词聚焦而降低其易读性/关键词密度；这些维度与去 AI 味含义不同。
- 不在本 change 中把改写服务产生的评估记录写入 ops-center SQLite；该跨进程持久化另建 change。

## Decisions

### D1: 适用性用维度字段表示，综合分按有效权重归一化

选择：每个维度序列化 applicable，默认 true。没有原文时克隆差异度为 false、得分和原始加权贡献为 0；综合分使用全部适用维度的加权和除以适用权重和。

备选：继续给固定中性分，或删除第 7 个维度。固定分会把无输入的信息伪装成质量证据；删除维度会破坏固定 15 维 API。保留维度并明确 N/A 兼顾可解释性和兼容性。

### D2: 统计旧记录以原文是否存在回退判定

选择：新记录写入 applicable；旧 dimensions_json 缺该字段时，统计服务仅对 clone_divergence 依据该记录的 original_content 是否非空推断，其他旧维度默认适用。

备选：把旧记录全部视作适用或迁移整表。前者会混入旧固定 60 分，后者改动/风险超过本次需要。按已存字段回退最小且可测试。

### D3: 模板结构与真实分点分别识别

选择：结构加分只认可编号列表、第一/第二/第三、其一/其二/其三、一是/二是/三是；首先/其次/最后仍可作为逻辑维度的模板扣分信号。

备选：两个维度都认可或都惩罚。都认可会自相矛盾；都惩罚会误伤真实编号论证。分离语义更符合可解释性。

### D4: 人类表达采用叙事/观点证据，不把网络口语当成唯一来源

选择：在已有口语词外，对重复第一人称叙事和显式个人观点给予有限加分，且不把我们当个人第一人称。

备选：大幅提高基础分或扩大所有人称加分。前者会掩盖模板；后者可能让我们应该式模板受益。限于个人第一人称和叙事/观点组合更稳健。

### D5: 关键词密度和易读性不充当 AI 检测器

选择：保留它们对焦点明确、句子简单内容的独立评估；以 human_likeness、logic 和结构信号约束模板整体质量。

备选：仅因模板取得高可读性或关键词分而扣分。这会让指标相互污染，违背老人和小孩能否读懂与 SEO 可读性的独立含义。

## Risks / Trade-offs

- [无原文的历史/新分数不可直接横比] -> 在专项文档和 API 明示 applicable_count/维度 N/A，最近 100 篇统计按同一规则计算。
- [词表存在假阳性/假阴性] -> 用模板、书面叙事、单字情感、克隆输入四类回归样本锁定；真实 LLM 数据到位后再基于标注数据校准。
- [旧记录缺少 applicable] -> 以已存 original_content 回退并用 API 回归测试锁定。
- [无有效维度导致除零] -> 评估器 fail-closed 返回 0 分，不抛除零错误。
- [前端把 N/A 显示为低分] -> 显式灰色 N/A 展示，不调用进度条的 0 分状态。

## Migration Plan

1. 发布新序列化字段；数据库不迁移，字段保存在已有 dimensions JSON。
2. 查询旧记录时按 original_content 回退；新旧记录可混合读取。
3. 若出现评分回归，可回滚代码，历史 JSON 仍能被旧版本忽略未知字段并读取。
