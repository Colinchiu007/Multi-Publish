# PRD — 视频创作·历史记录·任务详情页「查看文案」

- **状态**：开发完成（待 CI 合并）
- **分支**：`codex/view-copy-text`
- **关联页面**：视频创作 → 历史记录 → 任务详情页（编辑页）
- **创建日期**：2026-09-13

---

## 1. 背景

视频创作·历史记录的任务详情页（编辑页）在成品视频下方提供按钮操作区，当前已有【下载视频】等能力。用户希望在不离开编辑页的前提下，快速查看该任务对应的**全部文案文字**（按分段编号组织），并一键复制到剪贴板，便于二次编辑、复用或归档。

本需求在【下载视频】右侧新增【查看文案】按钮，通过模态弹窗展示全部文案并支持复制，不改动既有数据持久化结构与 IPC 契约。

## 2. 目标

- 在任务详情页（编辑页）成品视频下方按钮区，【下载视频】右侧新增【查看文案】按钮。
- 点击后打开模态弹窗，按分段编号展示全部文案文字。
- 弹窗底部提供【复制】按钮，一键将全部文案复制到剪贴板，并给出成功反馈。

## 4. 功能规格

### 4.1 按钮与入口

- **显示条件**：任务详情页（编辑页）成品视频下方按钮区存在【下载视频】按钮时，在其右侧显示【查看文案】按钮。
- **按钮文案**：`story2video.view_script` = 查看文案 / View Script。
- **点击行为**：打开文案模态弹窗（`script_modal_title` = 全部文案 / Full Script）。

### 4.2 文案来源与展示

- **文案来源**：读取任务对应的全部文案文字（分段结构），来源与任务详情页既有文案展示保持一致（同一份文案数据，不新增数据源）。
- **展示格式**：
  - 按分段编号组织，每段格式为 `【N】` + 文案内容。
  - 段与段之间用**双换行**（空行）分隔。
  - 某段无文案内容时，显示 `【N】（无文案）` 占位。
- **展示范围**：展示**全部**文案文字（所有分段），不做截断。

### 4.3 复制功能

- **复制内容**：与弹窗展示内容一致的全部文案文字（含分段编号、双换行分隔、空段占位）。
- **复制实现**：优先使用 `navigator.clipboard.writeText`；当剪贴板 API 不可用（非 HTTPS / 非安全上下文等）时，回退到创建临时 `textarea` 选中并执行 `document.execCommand('copy')` 的方式。
- **成功反馈**：复制成功后，按钮文案由「复制」变为「已复制」（`script_copied_button`），1.5 秒后自动恢复为「复制」。
- **失败处理**：复制失败时保留「复制」文案，可提示复制失败（不误报成功）。

### 4.4 弹窗交互

- **打开**：点击【查看文案】按钮打开模态弹窗。
- **关闭**：点击关闭按钮、遮罩或 Esc 关闭弹窗。
- **状态重置**：关闭弹窗时重置复制状态（若按钮处于「已复制」状态，恢复为「复制」）。

## 5. 数据校验

- **文案为空**：任务无任何文案分段时，弹窗展示空态提示（如「暂无文案」），【复制】按钮可禁用或复制空字符串。
- **空段**：分段存在但内容为空时，按「【N】（无文案）」占位展示，不跳过编号。
- **文案来源缺失**：无法读取到文案数据时，弹窗展示空态，不抛错崩溃。
- **剪贴板不可用**：`navigator.clipboard` 不存在或写入被拒绝时，回退 textarea 方式；两者都失败则提示复制失败。

## 6. 交互与提示文字

| 场景 | 中文文案 | 英文文案 | i18n key |
|------|---------|---------|----------|
| 查看文案按钮 | 查看文案 | View Script | `story2video.view_script` |

| 复制成功提示 | 文案已复制到剪贴板 | Script copied to clipboard | `story2video.script_copied` |

| 复制后按钮 | 已复制 | Copied | `story2video.script_copied_button` |

## 7. 边界情况

- 文案分段数量较多时，弹窗内容区支持滚动，不限制展示条数。
- 复制内容包含分段编号与双换行，粘贴后保持可读的分段结构。
- 连续多次点击【复制】：每次复制都重新写入剪贴板，成功后重新进入「已复制」状态并重新计时 1.5 秒。
- 复制成功后未关闭弹窗，1.5 秒后按钮自动恢复「复制」；期间再次点击可重新复制。
- 关闭弹窗后再次打开，按钮始终为「复制」初始状态。
- 空文案任务：弹窗展示空态，复制按钮复制空字符串或禁用。
