# 【图片轮播】流水线参数 UI/UE 优化建议方案（2026-08-06）

> 按需求第 15 项「分析选项过多问题，先出方案，确认后再执行」。方案确认后实施。

## 一、现状问题（基于 CreateView 表单实测）

1. **选项过多、层级扁平**：单页长表单（基础→画面→声音→高级→模板与输出→发布）约 40+ 控件全部平铺，无分组折叠；声音区叠加 provider/model/音色下拉与音色克隆面板后尤其密集，用户容易迷失。
2. **常用/高级边界不清晰**：除「部分高级运行参数由系统默认值管理」一句提示外，哪些字段可安全忽略、哪些影响成片效果没有引导。
3. **启动入口不突出**：操作栏（启动/取消）在长表单底部，滚动后不可见；运行期阶段进度在表单顶部，长表单下被推离视线。
4. **缺“已保存/恢复”可见反馈**：上次选项已自动保存/恢复，但无任何提示，用户不知道设置已被记住。
5. **宽窄屏适配不足**：表单为单列全宽，窄窗口下控件换行混乱。

## 二、优化方案

### 2.1 表单分组 + 折叠（手风琴）
- 按「基础」「画面」「声音」「高级」「模板与输出」「发布」分组，每组标题栏带图标 + 当前摘要（如“声音：MiniMax · 男声清涩”）+ 折叠箭头。
- 默认：基础/画面/声音 展开；高级/发布 折叠（发布默认关闭时显示“未启用”摘要）。
- 折叠状态随选项持久化一起保存（`story2video.lastOptions.v1` 增加 `ui` 段），下次进入恢复。
- 交互：点击标题栏切换；动画平滑；不阻塞运行中（运行期禁用折叠并高亮当前阶段所在组）。

### 2.2 常用/高级分层
- 每组内字段按频率分两级：常用字段正常显示；低频字段（负向提示词、分句微调、字幕字号等）放入组内「高级设置」子折叠。
- 字段名右侧提供 `?` 帮助（tooltip），文案来自 PRD 合同描述（本地化）。

### 2.3 启动入口与进度固定
- 操作栏（启动流水线 / 取消 / 恢复默认选项）改为 sticky 固定在表单可视区顶部下方；运行期进度条 + 已用时 + 阶段清单固定显示，表单滚动不脱离视线。

### 2.4 保存/恢复可见反馈
- 选项自动保存后，操作栏旁短暂显示「选项已保存 ✓」（1.5s 淡出）；进入页面恢复上次选项时显示「已恢复上次的选项设置」轻提示。
- 恢复默认选项按钮保留（已有），确认弹窗后重置。

### 2.5 声音区专项优化
- provider → model → 音色 三步下拉保持但收紧间距；音色克隆面板默认折叠为「+ 克隆音色」入口，展开后显示上传区与要求提示（格式/时长/大小）。
- 音色目录加载态显示骨架/禁用，错误态显示友好提示（已有文案）。

### 2.6 响应式
- ≥1200px：基础/画面两列布局；声音区单列；高级折叠。
- <1200px：全部单列。

## 三、数据与交互合同

| 项 | 合同 |
|----|------|
| 折叠状态 | 存入 `story2video.lastOptions.v1.ui = { expandedGroups: string[] }`；类型校验失败回退默认（基础/画面/声音展开）。 |
| 摘要 | 每组摘要取该组首个非默认项，避免泄漏敏感内容；声音组摘要显示 provider 名与音色名（本地化）。 |
| 帮助文案 | 使用 locale 资源（zh/en），默认中文；复用现有 `translateWithLocaleFallback`。 |
| 运行期 | 运行中锁定折叠与表单编辑能力不变（沿用现有 disable 逻辑），仅新增进度固定展示。 |
| 兼容 | 不改动 s2vConfig 数据结构与 IPC 契约；纯展示层改动，回归 = 现有 190+ 项组件测试 + 视觉回归。 |

## 四、实施步骤（确认后执行）

1. CreateView 模板按 6 分组重构 + 折叠/摘要/帮助 tooltip（.vue + 少量 CSS）。
2. `story2video.lastOptions.v1` 快照增加 `ui.expandedGroups`，保存/恢复逻辑扩展 + 类型校验。
3. 操作栏与进度区 sticky；保存/恢复轻提示。
4. 声音克隆面板折叠化。
5. 响应式两列布局。
6. 组件测试（分组渲染/摘要/折叠持久化/提示）+ `vite build` 模板校验。
