## Story2Video 场景上下文增强中间层 — 体验/验收记录（2026-08-12）

### 第 1 层：引擎直调（story-context-engine，无需外部 key）
- 核心示例：唐代全文 + 「一个老妇人在做饭」→ storyContext=`中国唐朝（618-907）时期长安民居厨房中，一个老妇人在做饭；视觉唐代宫殿、长安城、圆领袍、襦裙、金红色盛唐光线；使用土灶、柴火、陶罐、铜锅；光线平和`
- 负面锚点：`电烤箱 / 微波炉 / 冰箱 / 燃气灶 / 电磁炉…`（含电烤箱/微波炉/西式现代厨房）
- 无关键词文案不编造；现代文案不误判古代；城堡题材不编造城市（region 为空）

### 第 2 层：真实 prompt-engine（8013）提示词 A/B
- A 组（带 scene_context 上下文 + 时代负面锚点）：✅ 提示词含 Tang Dynasty / Chang'an / Chinese / earthen stove / firewood / clay pot 等锚点
- B 组（对照组，仅原文）：✅ 无时代/地域锚点（泛化厨房场景）
- 结论：PASS — 中间层把全局故事背景真实注入下游提示词，背景漂移（西方老太太/现代厨房）被锚点+负面提示双重约束

### 后续验收层（外部边界）
- 第 3 层：真实图片生成（需图片 provider key，人工目视对比 A/B 出图）
- 第 4 层：桌面端完整体验（Electron 可见窗口跑 story2video-compose）

> 证据边界：第 1-2 层为本地可复现契约/服务证据；第 3 层依赖第三方图片厂商模型行为，属外部验收。
