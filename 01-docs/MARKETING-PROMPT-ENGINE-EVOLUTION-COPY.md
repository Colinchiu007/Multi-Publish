## 1. 官网版（长文，承载转化）

> 用于产品官网 landing page / 功能页。

### 标题候选
- A：**"越用越懂你"：你的 AI 创作，从此不再从零开始**
- B：**告别"掷骰子式"生成——让创作引擎记住你**

### 正文

**AI 创作最大的浪费，是你每天都在"重新认识它"。**

同一个主题，今天生成的结果和明天完全不同；上次调出来的好效果，换个说法就再也找不回来。生成工具层出不穷，但**没有一款记得你是谁、你喜欢什么**。

Multi-Publish 智能创作引擎，第一次让"生成"变成"成长"。

**它记住你的每一次选择。** 你选中哪张图、重新生成了几次、下载了什么、发布了什么——这些你本来就会做的操作，就是它学习的信号。不需要打分，不需要写评价，**你正常用，它默默懂**。

**它让好的经验沉淀下来。** 你常选"前后对比构图+高饱和配色"，同类主题再生成时，这个方向自动排到最前面。第 1 次是随机，第 50 次是你喜欢的样子——**工具的价值，随使用时间增长，而不是折旧**。

**它把探索留给便宜的地方，把稳定留给贵重的地方。** 图片生成成本低，系统大胆试新组合、自动淘汰差方案；视频生成成本高，只有经过验证的配方才会被采用——**快的地方敢创新，贵的地方求稳**。

**它不是黑盒。** 每次推荐都有据可查，学到的经验要过六重门禁才生效，效果下滑自动回退，数据默认留在本机、可一键关闭。

**不是生成一次，而是成长每一次。**

## 3. 客户 PPT 版（一页一卖点，商务演示）

> 用于销售对客户宣讲，每页核心一句 + 支撑点。

### 封面
**Multi-Publish 智能创作引擎**
**越用越懂你，越做越像你**

### P1 问题
**AI 生成不可控、经验不沉淀、内容同质化**
- 同一主题每次结果天差地别
- 好配方无法积累，换个说法就归零
- 千篇一律，没有辨识度

### P2 方案
**不是又一个生成器，而是会成长的创作伙伴**
- 每一次生成/点击/发布 → 下一次更好
- 经验随使用沉淀，价值随使用增长

### P3 卖点一：长期记忆
**系统记住你的偏好，同类主题优先给对的方向**
- 第 1 次随机撞运气，第 50 次你喜欢的都在前排

### P4 卖点二：零负担
**不需要打分写评价，正常使用就是反馈**
- 唯一可选按钮「存为模板」，不点也能进化

### P5 卖点三：聪明的成本策略
**图片激进探索，视频保守求稳**
- 探索成本花在便宜处，确定性留给贵重处

### P6 卖点四：企业级信任
**可解释、可回退、可关闭**
- 推荐有据可查；经验过六重门禁；效果下滑自动回退；数据留本地、一键关闭

### P7 差异化
**记忆 / 个性化 / 可解释 / 零负担 / 成本策略** —— 五项全面领先通用平台

### P8 路线图
P0 数据管道（已上线）→ P1 评分排序+记忆库 → P2 视频配方+平台回灌 → P3 语义理解+自动进化

### P9 结尾
**AI 的终点不是生成，而是记住你。**

## 4. 卖点打磨稿（卖点 1：「越用越懂你」）

### 4.1 打磨后完整文案

> ### 卖点 1：「越用越懂你」—— 每个创作者都该有一台专属引擎
>
> **你的每一次选择，都在训练你的专属引擎。**
>
> 你选中哪张图、跳过哪个方案、重新生成了几次、最终发布了什么——这些细微动作，构成了一幅只有你才有的"偏好地图"。系统不问你、不打扰你，只是安静地把它记下来。
>
> 下一次，当你在同类主题里再次创作，你常选的"前后对比构图、书本特写、高饱和配色"会自然地排到最前面。你甚至说不清它是什么时候开始懂你的——你只会发现：**重新生成的次数越来越少，作品越来越像"你"。**
>
> 第 1 次，它给你看世界；第 50 次，它给你看你喜欢的世界。
>
> 别人的工具越用越旧，你的越用越懂你。

### 4.2 打磨对比（前 → 后）

| | 打磨前 | 打磨后 |
|---|---|---|
| 核心句 | "系统记录每次生成的完整链路，自动学习你的偏好" | **"你的每一次选择，都在训练你的专属引擎。"** |
| 用户价值 | "生成质量持续上升、返工越来越少" | **"不是工具越来越强，是它越来越像你。"** |
| 记忆感 | "第 1 次和第 50 次完全是两个产品" | **"第 1 次它给你看世界，第 50 次它给你看你喜欢的世界。"** |
| 差异化 | "工具的价值随使用时间增长，而不是折旧" | **"别人的工具越用越旧，你的越用越懂你。"** |

### 4.3 打磨方法论

1. **把"系统"换成"你"**：原文案主语是"系统记录…自动学习"（工具视角），改成"你的每一次选择…训练你的专属引擎"（用户视角）——**让用户感到主动权在自己手里**；
2. **具象化偏好**："前后对比构图+高饱和配色"比抽象的"你的偏好"更有画面感，用户能对号入座；
3. **制造反差句**："第 1 次给你看世界 / 第 50 次给你看你喜欢的世界""别人的越用越旧 / 你的越用越懂你"——**反差句是最容易记住和转发的传播点**；
4. **删掉数字承诺**：不说"返工减少 50%"这种需要证据的话，用"越来越少"的主观体感，避免过度承诺。
