# 图片轮播配置体验优化方案（已确认实施，2026-08-05）

> **性质：已确认的 UE 实施方案。** 本次只重排信息架构与运行反馈表现，不删除、迁移或改变任何现有图片轮播能力、数据合同或通用流水线 checkpoint 能力。

## 观察

当前创作页把内容类型、图片/提示词、语音、分句、模板、动效、字幕、BGM、水印、发布与输出参数同时平铺，接近三十个决策点。
这会让普通创作者难以判断“必须选择什么”，也难以理解图片风格、提示词风格、模型和音色之间的职责差异。

运行态更适合使用阶段清单：当前阶段高亮，之后依序列出“文案拆分、内容增强、画面提示词优化、生成图片与旁白、合成轮播视频、发布（可选）”，
并显示“执行中 / 等待 / 完成 / 跳过 / 失败 / 需要处理”。图片轮播不应以 S2V 百分比作为主要或辅助进度表达。

## 推荐方案：五个可折叠区的渐进披露表单

推荐在**不删除现有字段和能力**的前提下，把同一页表单组织为以下五个区块：

| 区块 | 初始状态 | 建议承载内容 | 边界 |
|------|----------|--------------|------|
| **基础** | **默认展开，初始只显示本区字段** | 文案输入、6,000 字符计数、内容类型、分句语言“自动识别”、基础模板/比例摘要 | 首屏主按钮为“启动流水线”；不展示 checkpoint、并发数、音调或创意强度 |
| **外观** | 默认折叠 | 图片生成器、图片风格、提示词风格、动效、转场、字幕、BGM、水印 | 图片风格决定最终视觉输出；提示词风格决定提示词写法/组织方式，必须保留为两个不同选项 |
| **声音** | 默认折叠 | TTS provider、model、音色目录、目录状态、刷新、默认选择；有能力时的个人音色入口 | 先 provider/model 再音色；Doubao 只显示官方控制台创建后刷新/选择的说明，未验证 API 时不假装已同步槽位 |
| **高级** | 默认折叠 | 分句模式、句长、目标时长、负向提示词、输出细节等已有高级能力 | 音调、并发数和创意强度仍为受控默认，不因放入“高级”而重新暴露给用户 |
| **发布** | 默认折叠 | 平台、标题、标签、正文、封面和发布开关 | 保留既有发布合同；未启用时运行态第六阶段显示“跳过” |

折叠标题可显示已选摘要，例如“基础：自动识别 · 均衡 · 约 6 秒/场景”或“声音：ElevenLabs · 模型名 · 已缓存目录”，
但不应虚构成本、可用音色或 provider 状态。

## 运行态建议

- 当前阶段整行浅色高亮并标注“执行中”，可展示短动作，例如“正在生成第 3/8 张画面”。
- 后续阶段使用“等待”；完成与跳过显示结果摘要；失败显示安全的错误摘要和取消入口。
- 内容政策连续 5 次明确拒绝时显示“图片内容需要修改”及“可能存在内容风险，请修改文案后重新启动”。该状态要求取消旧 run 后新建 run，而不是提供继续/推进按钮。
- 图片轮播始终运行固定六阶段自动流；UI 不出现人工 checkpoint、恢复或推进动作。

## 取舍与确认点

| 方案 | 优点 | 风险 | 结论 |
|------|------|------|------|
| 五区折叠单页 | 保留现有 URL、状态和功能面，首屏决策最少 | 需要设计依赖状态、摘要和视觉回归 | **已确认实施** |
| 三步向导 | 新手路径更短 | 高级用户回跳与编辑成本高，容易改变既有合同 | 暂不选 |
| 完全卡片化设置 | 视觉更丰富 | 仍可能塞入大量决策点，改造和回归范围大 | 暂不选 |

实施前已确认的范围：

1. 采用“基础 / 外观 / 声音 / 高级 / 发布”五区折叠，仅“基础”默认展开。
2. 基础摘要只显示可由本地状态计算的场景/时长信息；没有可信计费或配额数据时不显示价格。
3. “发布”继续保留在创作页折叠区，未启用时六阶段清单显示“跳过”。

本方案与 PRD 中已确认的本地化、阶段清单、受控默认和音色隐私合同兼容。本次实现仍必须验证不会删除功能、改变已有数据或声称 OpsCenter/Doubao/克隆能力已交付；真实 provider 目录、个人槽位、克隆和内容政策降级继续标记为 `PENDING_EXTERNAL`。
