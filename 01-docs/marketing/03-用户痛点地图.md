## ⚠️ v0.2 重大修正：客群优先级判断反了

v0.1 我写「矩阵号团队是付费主力，个人创作者付费意愿最低」。
**实读代码后，这个判断需要推翻。**

| 证据 | 数值 | 含义 |
|---|---|---|
| 队列并发 | **3** | 跑不了工业化铺量 |
| 各家 `maxConcurrent` | **2~3** | 模型调用也是低并发 |
| 定价 标准版 | **¥29/月** | 定的是个人/小团队价位 |
| 定价 专业版 | **¥79/月** | 更高的个人/小团队价位 |
| 定价企业版 | **不存在** | 代码里只有 `free` / `standard` / `pro` 三档，**无企业版** |
| 官方 README 定位 | 「**自媒体运营**」 | 团队自己写的是运营者，不是工厂 |

### 修正后的判断

> **真实能力画像是「一个认真做内容的创作者，一天省 2 小时」，不是「MCN 的工业化产线」。**

**为什么不修正会出事**：矩阵客户上手发现并发 3，一天发不完，
**比不卖还伤口碑**（`01-docs/learnings.md` 里团队自己反复强调"最便宜的硬回归网"，
说明团队对"说出去要能复现"这件事的痛感很强）。

**修正后的客群优先级：**

| 优先级 | 人群 | 理由 |
|---|---|---|
| 🥇 **主打** | 个人创作者 / 自媒体运营 | 痛点最锋利、价位匹配（¥29 起）、能力对得上 |
| 🥈 **谨慎** | 代运营 / 服务商 | 需求真实（掉线、串号），但权限协作缺失 |
| 🥉 **暂缓** | 矩阵号 / MCN | 需求大但**当前能力撑不住**，说大了打脸 |
| ⛔ **不打** | 电商 / 品牌方 | 客群定位零验证 |

> ⚠️ **"暂缓"不等于"放弃"**。矩阵人群是真需求，
> 只是**要等并发/稳定性能力上来再打**。见第七节。

## 一、总览：四类人群，一句话诊断

| 人群 | 真实身份 | 核心痛点 | 付费意愿 | 能力匹配 | 优先级 |
|---|---|---|---|---|---|
| **个人创作者 / 自媒体运营** | 副业或小团队，1~3 个号 | 发得多但没量，时间不够 | 中（¥29 起可承受） | ✅ **完全对得上** | 🥇 **主打** |
| **代运营 / 服务商** | 手上几十个客户号 | 客户号出事 = 事故 | 高 | ⚠️ 一半对得上 | 🥈 谨慎 |
| **矩阵号团队 / MCN** | 3~20 个号，有专人 | 铺量铺不动 | **高** | ❌ **并发 3 撑不住** | 🥉 暂缓 |
| **电商 / 品牌方** | 自有品牌 | 内容产能不够 | 待验证 | ❌ | ⛔ 不打 |

**关键结论：v0.1 说反了。**
最好讲的人群（个人创作者）**恰好是能力最匹配、价位最合适**的主力客群。
矩阵团队付费意愿最高，但**当前并发 3 的能力接不住** —— 先别打。

## 二、个人创作者 / 一人工作室

### 他们是谁

- 副业做号，或者一个人的小工作室
- 1~3 个平台账号，同时在好几个平台更新
- 没有团队，没有预算，靠自己做
- 白天上班，晚上做内容

### 痛点链路（卡在哪一步）

```
想选题 → ✗ 不知道拍什么
   ↓
找素材 → ✗ 想跟对标，只能天天刷主页
   ↓
写内容 → ✓ 用 AI 写
   ↓
去 AI 味 → ✗✗✗ **最大断点**：AI 味重 → 平台限流 → 发了白发
   ↓
做视频 → ✗ 改完文案音画对不上
   ↓
做封面 → ✗ 还得再开个工具
   ↓
多平台发 → ✗✗ 开 7 个后台传 7 次
   ↓
看数据 → ✗ 发完就石沉大海
```

**两个致命断点：**

| 断点 | 为什么致命 | 对应卖点 |
|---|---|---|
| **去 AI 味** | 直接导致「发了白发」= 收益归零，痛感最强、最具体 | **S-04** ✅ |
| **多平台发布** | 每条内容都要付一小时，是纯重复劳动 | **S-11** ✅ |

### 决策因素

| 因素 | 权重 | 说明 |
|---|---|---|
| 有没有用 | ⭐⭐⭐⭐⭐ | 「真能发出去吗」——第一句话就问这个 |
| 多少钱 | ⭐⭐⭐⭐ | 副业人群对价格极敏感，几百块能试、几百块月付就不能 |
| 好不好上手 | ⭐⭐⭐ | 「我不会弄电脑」是真实门槛 |
| 涨不涨粉 | ⭐⭐⭐ | 会问但我们答不了 → **预期管理点** |
| 功能够不够 | ⭐ | 他们说不清自己要什么，只说"太麻烦了" |

### 说服路径

> **S-04 讲钱**（AI 味 = 没流量 = 白发）
> → **S-11 讲时间**（每天省一小时）
> → **S-48 讲生活**（晚上一小时搞定，不用熬夜）

**开场不要讲功能，要讲他昨天刚受过的气。**
参考 `02` 钩子 H-01「我发一条视频要开 15 个后台」。

### ⚠️ 预期管理（必须主动做）

**他们会问「用了能涨粉吗」——我们答不了。**

- ❌ 别说「能涨粉」（做不到，会毁掉所有信任）
- ✅ 说「保证不白发」——**我们承诺的是下限，不是上限**

> 这个区分极其重要。产品能保证的是「不浪费你的时间」，
> 不能保证「一定爆」。**说清下限，用户反而更信。**

> 💡 **v0.2 好消息**：定价已经定了 —— **免费版 ¥0（5 平台/每天 5 篇/并发 1）/ 标准版 ¥29 月 · ¥199 年 / 专业版 ¥79 月 · ¥599 年**。
> 免费版门槛很低，**这批人完全能低风险试**。「试错成本低」（S-64）现在有实证了。
> ~~另有冷启动政策：前 200 名年付 ¥99 终身锁定。~~ —— ❌ **该政策已于 2026-10-07 取消，不要再提。**

### 缺口

| 缺什么 | 影响 |
|---|---|
| **真实效果数据** | ❗ 改前/改后对比是 S-04 唯一的武器 |
| 新手引导 / 示例库 | 一个人摸索会直接放弃 |
| 省时量化数据 | 填 `01` §7.2 测算表，把 S-47 升 S |

## 三、矩阵号团队 / MCN　`🥉 暂缓（能力接不住）`

> ⚠️ **v0.2 降级**：v0.1 把这人群当付费主力是判断错误。
> 代码实证并发 **3**（标准版），定价标准版 ¥29，官方定位「自媒体运营」——
> **这套组合是给个人/小团队的，不是给工厂的。**
> **先别打这群人**，说大了会打脸。

### 他们是谁

- 3~20 个账号同时运营
- 有专人（通常是 3~10 人的小团队）
- 内容以二创/混剪/信息差为主，产量就是竞争力
- 老板关心 ROI，运营关心别加班

### 痛点链路

```
批量找素材 → ✗ 人工翻主页找爆款，一天能找到 5 条就不错
   ↓
批量改写 → ✗✗✗ **最大断点**：工具都是逐条操作，改 50 条要点 50 次
   ↓
批量发布 → ✗✗ 20 个号 × 15 平台 = 300 次操作，铺量就是靠人力堆
   ↓
查漏补缺 → ✗✗✗ **隐形杀手**：发没发出去？漏发了哪条？没人知道
   ↓
算 ROI → ✗ 数据在各个后台，汇总不起来
```

**三个断点：**

| 断点 | 后果 | 对应卖点 | v0.2 实证状态 |
|---|---|---|---|
| **批量改写** | 产能被人力卡死 | S-05 | ✅ 已实现 |
| **批量发布** | 铺量铺不动 | S-18 | ⚠️ **并发 3，接不住工业量** |
| **查漏补缺** | **漏发 = 事故** | S-37 | ✅ 重试 + 崩溃恢复已实现 |

### 决策因素

| 因素 | 权重 | 说明 |
|---|---|---|
| **撑不撑得住量** | ⭐⭐⭐⭐⭐ | 「我 20 个号跑得动吗」→ **我们答：并发 3** |
| **稳不稳** | ⭐⭐⭐⭐⭐ | 「崩了谁负责」→ 崩溃恢复已实现 ✅ |
| **会不会串号** | ⭐⭐⭐⭐ | 一次串号可能直接丢客户 → 🔶 未实测 |
| 有没有日志能查 | ⭐⭐⭐⭐ | ❌ 没有 |
| 能不能给不同人不同权限 | ⭐⭐⭐ | ❌ 没有 |
| 价格 | ⭐⭐⭐ | ¥29 标准版 / ¥79 专业版，量大的团队预算反而充足 |
| 界面好不好看 | ⭐ | 几乎不关心，能用就行 |

### ⚠️ 为什么"暂缓"：诚实对照表

**如果现在接了矩阵客户，他上手会问这些：**

| 他问 | 我们的真实答案 | 结果 |
|---|---|---|
| 「20 个号一起跑行吗？」 | **并发 3**，要排队 | 😬 预期落空 |
| 「能加到并发 20 吗？」 | 没说能做 | 😬 |
| 「崩了能接着发吗？」 | ✅ 能，持久化队列 | 🙂 |
| 「有日志吗？」 | ❌ 没有 | 😬 |
| 「谁能操作？能审计吗？」 | ❌ 没有 | 😬 |

**五个问题里三个答不上来 —— 现在打这群人是拿口碑换短期成交。**

### 什么时候可以重启打这人群

产品侧要补上（按优先级）：

| 待补 | 为什么必须 | 现状 |
|---|---|---|
| **并发可调** | 让他们自己决定跑多快，比我们承诺更快更可信 | 固定 3 |
| **运行日志 + 审计** | 「谁发的」「为什么失败」是准入门槛 | 无 |
| **失败原因可查** | 漏发事故要能复盘 | 有重试，无归因 |
| **团队权限** | 人一多就必需 | 无 |

**→ 这不是写文档能解决的，是产品排期。** 见第七节。

### 对话策略（万一客户主动来问）

> **别说**：「支持矩阵铺量」「点一次全铺完」 ❌
> **要说**：「批量提交 + 队列自动排，崩了下次接着发。目前是 3 任务并发，
> 您的量如果更大，我们可以聊聊定制。」 ✅

**主动把限制说在前面，比被客户发现后强十倍。**

### 决策链

```
运营试用（自己爽） → 拿数据汇报 → 老板问"稳不稳" → 运维/技术问"崩了怎么办"
                                              ↓
                                    ⚠️ 断点在这两关
                                              ↓
                                     技术答不上 = 死
```

**我们目前只在"运营试用"这一关有优势。** 后两关（老板、运维）是空的。

### 缺口

- 稳定性能力的完整盘点（**最高优先**）
- 压力测试数据（多少号 × 多少条 = 不崩）
- 团队协作 / 权限
- 批量操作的审计日志

## 四、代运营 / 服务商　`🥈 利润最厚`

### 他们是谁

- 帮客户代运营账号，一个人管 10~50 个客户号
- 收费按月/按账号数，**人力密集**
- **他们的成本 = 人力，所以最在意"能不能少雇人"**
- 客户关系是他们的资产，最怕出事

### 痛点链路

```
管客户账号 → ✗✗✗ **最大断点**：几十个客户号散在各个平台后台
   ↓
盯登录态 → ✗✗ 客户号掉登录，被客户找上门 = 售后事故
   ↓
发内容 → ✗ 一个人手工发几十个号
   ↓
串号风险 → ✗✗✗ **隐形杀手**：A 客户内容发到 B 客户号 = 直接丢客户
   ↓
交接给运营 → ✗ 客户换人，历史内容/账号信息带不走
```

**两个致命断点：**

| 断点 | 后果 | 对应卖点 | 状态 |
|---|---|---|---|
| **客户号掉登录** | 售后事故，赔钱赔时间 | **S-17** ✅ | 已确认 |
| **串号** | **一次 = 丢一个客户**，一年白干 | S-39 🔶 | 待核实 |

### 决策因素

| 因素 | 权重 | 说明 |
|---|---|---|
| **会不会出事故** | ⭐⭐⭐⭐⭐ | 串号、掉线，都是赔钱的事 |
| 能不能少雇人 | ⭐⭐⭐⭐ | 他们的利润 = 收入 − 人力 |
| 数据能不能带走 | ⭐⭐⭐⭐ | 客户换人不给数据 = 纠纷 |
| 效率 | ⭐⭐⭐ | 反而没那么重要 |
| 价格 | ⭐⭐⭐ | 工具成本要低于省下来的人力 |
| 界面 | ⭐ | 不关心 |

**他们买的是风险规避，不是效率。** 这是和其他人群最大的区别。

### 说服路径

> **开场别讲七个平台**——那是 S 端的话术
> → **S-17 掉线可见**（「昨天客户问我，我的号怎么掉登录了」）
> → **S-39 不串号**（串一次，客户就走了）
> → **S-44 能导出**（客户要数据你给得出）
> → 收尾：**S-19/S-46 少雇一个人**（人力成本是他们全部的利润来源）

参考 `02` 钩子 H-04、slogan L-17 / L-18。

### 卖点缺口

| 缺什么 | 影响 |
|---|---|
| 多客户/多账号的归属与权限 | 团队内部谁管哪个客户 |
| 团队协作 | 运营之间怎么交接 |
| 操作审计 | 客户问"这条谁发的"，要能查 |
| 数据导出 | 客户要带走怎么办（`01` 里 S-44 只是卖点方向，无细节） |
| 客户隔离的隔离级别 | 是不是真的物理隔离，还是逻辑隔离 |

### 额外机会点（未在 01 梳理）

这类人群有个天然需求：**客户自助查数据**。
如果产品能出一个给客户看的只读页面/报告，代运营可以直接发给客户当交付物 —— 
这既是他们的卖点，也是我们的**续费理由**（用得越多越离不开）。

> 这条值得单独评估：**"给客户看的报告"可能是一个被忽略的功能位。**

## 五、电商 / 品牌方　`⛔ 先别打`

### 现状

- **是否在目标客群内，完全没验证过。**
- 假设他们在关心：品牌资产安全、素材版权、合规、可审计、内容合规风险。

### 为什么不建议现在投入

1. 需求假设全是猜的，没有一条来自真实用户
2. 品牌方的合规要求和创作者完全不同，产品大概率不满足
3. 投放素材要重新做一批，成本不低
4. **先验证有人买单再投入**

### 什么时候可以重启

出现以下任一信号：
- 已有电商/品牌客户主动来问
- 销售过程中被这类客户问倒过
- 创作者客群里这类人占比明显

## 八、下一步建议（按优先级）

### 🔴 立刻做

1. **盘点矩阵人群的稳定性能力** —— 并发上限、失败重试、日志、审计、权限到底有没有。

### 🟡 尽快做

4. **准备真实效果数据** —— 「改前/改后」对比是 S-04 唯一的武器
5. **填 `01` 第 7.2 节省时测算表** —— 有了数字，三类人群都能讲价值
