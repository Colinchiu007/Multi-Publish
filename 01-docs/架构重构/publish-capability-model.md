# 发布能力模型（Stage 2 域收敛，2026-09-02）

## 概述

定义各平台的发布能力统一模型，作为发布器接口的单一事实来源。

| 平台 | 发布模式 | 内容类型 | 认证方式 | 状态 |
|------|---------|---------|---------|------|
| 微信公众号 | RPA | 图文 | Cookie | ✅ |
| 抖音 | API+RPA | 图文/视频 | Cookie+API Key | ✅ |
| 知乎 | RPA | 文章 | Cookie | ✅ |
| 微博 | RPA | 图文 | Cookie | ✅ |
| B站 | API+RPA | 专栏/视频 | Cookie+API Key | ✅ |
| 小红书 | RPA | 图文 | Cookie | ✅ |
| 视频号 | RPA | 视频/图文 | Cookie | ✅ |
| 快手 | RPA | 视频/图文 | Cookie | ✅ |
| 今日头条 | RPA | 图文/视频 | Cookie | ✅ |
| YouTube | RPA | 视频 | OAuth 2.0 | ✅ |
| TikTok | RPA | 视频 | OAuth 2.0 | ✅ |
| Twitter/X | RPA | 图文 | Cookie | ✅ |

## 发布能力分类

| 能力 | 说明 | 支持平台 |
|------|------|---------|
| 图文发布 | 标题+正文+封面图 | 全部 |
| 视频发布 | 视频文件+标题+描述 | 抖音/视频号/快手/YouTube/TikTok/B站/Instagram/Facebook |
| 定时发布 | 设定时间自动发布 | 全部 |
| 批量发布 | 多平台同时发布 | 全部 |
| 多账号发布 | 同平台多账号发布 | 全部 |
| 发布后监控 | 轮询审核状态 | 全部 |
| 断点恢复 | 中断后从断点继续 | RPA模式 |

## 发布流程统一模型

```
1. 内容准备 → 2. 平台选择 → 3. 格式转换 → 4. 登录态验证 → 5. 发布执行 → 6. 结果记录
     │              │              │              │              │              │
     ▼              ▼              ▼              ▼              ▼              ▼
  Quill编辑器    平台勾选    平台适配器   Cookie/OAuth    RPA/API        SQLite
  富文本编辑     多选支持    截断/转换    自动检测       执行引擎       历史记录
```

## 降级策略

| 场景 | 策略 |
|------|------|
| API失败 | 自动切换RPA模式 |
| RPA失败2次 | 提示手动发布 |
| 某平台失败 | 标记失败，不影响其他平台 |
| 用户取消 | 停止当前操作，后续步骤取消 |
